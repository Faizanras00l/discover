# Discover Lahore

**An innovative smart tourism companion for Lahore, offering personalized journeys, real-time guidance, and cultural insights for both local and foreign tourists.**

> **Note:** This is a working prototype designed to demonstrate the user experience and core features of the Discover Lahore platform.

## 🌟 Introduction

Discover Lahore is designed to revolutionize how tourists experience the historic and vibrant city of Lahore. Whether you are a foreign traveler looking for a safe and curated experience or a local looking to rediscover your heritage, this app adapts to your needs.

With features like real-time translation, smart hotel recommendations, and an exclusive "Aesthetic Mode" for photographers, Discover Lahore is your ultimate travel partner.

## 🚀 Key Features

*   **👥 Dual Tourist Modes:**
    *   **Foreign Tourist Mode:** Prioritizes safety, guided tours, and translation services.
    *   **Local Tourist Mode:** Focuses on hidden gems, events, and cultural deep-dives.
*   **🗺️ Live Interaction Map:** Real-time navigation to key landmarks.
*   **🗣️ Instant Translation:** Break language barriers with built-in translation tools.
*   **📅 Event Finder:** Stay updated with the latest happenings, festivals, and cultural events in the city.
*   **🛡️ Safety Hub:** Integrated safety features including emergency contacts and safe routes.
*   **🏨 Smart Hotel:** Intelligent accommodation recommendations based on your itinerary and budget.
*   **🎨 Aesthetic Mode:** A unique feature providing curated visual guides and photo spots for content creators and photographers.
*   **📝 Trip Planner:** Customizable itineraries to help you plan your perfect journey.

## 🛠️ Technology Stack

This prototype is built with modern web technologies for rapid development and ease of use:

*   **HTML5:** Semantic structure.
*   **Tailwind CSS (via CDN):** Rapid styling and responsive design.
*   **JavaScript (Vanilla):** Light interactivity and logic.
*   **Google Fonts:** Using *Plus Jakarta Sans* and *Manrope* for modern typography.
*   **Material Symbols:** High-quality icons from Google.

## 🚀 Getting Started

Since this is a client-side prototype, no complex build process is required!

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Faizanras00l/discover.git
    ```
2.  **Open the project:**
    Navigate to the project folder.
3.  **Launch the App:**
    Simply double-click `index.html` to open it in your web browser.
